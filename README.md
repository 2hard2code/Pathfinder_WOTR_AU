The script requires [7z.exe](https://github.com/ip7z/7zip) to be available in the system PATH.

1. Run [upgrade.js], it will create [in, out, backup] folders.
2. Move one of the save files to [in].
3. Run [upgrade.js], now it will change each existing squad in your armies to 10,000,000 rangers, it will also increase the maximum number of squads to 7.
4. Move the save file from [out] to your game folder.
5. Profit.

Folder [backup] receives the unmodified copy of the save file, so you can use it for recovery.
